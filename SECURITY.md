# Security Policy

## Reporting a vulnerability

Email **masstransferase.github@gmail.com** with the subject `KREN security report`. Do not open a public issue for an unpatched vulnerability. Do not send API keys, confidential selected text, complete provider responses, or credential-bearing logs. Revoke any exposed key immediately at its provider.

Include the KREN and VS Code versions, affected operation, impact, and reproduction steps using invented or public sample text. A minimal proof of concept is welcome when it contains no credentials or private data. Reports are handled on a best-effort basis without a guaranteed response time. Please allow reasonable time for investigation and a coordinated fix before public disclosure.

## Supported versions

| Version | Security support |
| --- | --- |
| Latest `1.x` Marketplace release | Supported |
| Older public releases | Update to the latest release first |
| Private preview and development builds | Unsupported |

Provider outages, quota limits, account billing, and provider-side retention policy questions are not KREN vulnerabilities. Report defects that expose unintended text, credentials, local files, executable control, or unauthorized network destinations through the private channel above.
