# Support

Start with the [User Manual](docs/USER_GUIDE.md), [Troubleshooting](docs/TROUBLESHOOTING.md), and [Provider Setup](docs/PROVIDER_SETUP.md). Search existing issues before opening a new bug report or feature request.

For a reproducible problem, include the KREN and VS Code versions, operating system or remote-host arrangement, operation, provider and model, relevant status code, and invented or public sample input. Never include credentials, confidential text, complete provider payloads, private filenames, or sensitive paths.

Community support is best effort and has no guaranteed response time. Provider account recovery, billing disputes, quota increases, API-key issuance, and third-party service availability must be handled by that provider. Security vulnerabilities belong in the private channel described in [Security Policy](SECURITY.md), not a public issue.
